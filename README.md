# Gradient Surfing

Source for [Gradient Surfing](https://gradientsurfing.com): an ML blog where posts and their supporting experiments live together.

## Local development

Install [Quarto](https://quarto.org/docs/get-started/) and render or preview the site:

```bash
quarto preview
```

The generated site is written to `_site/` and is intentionally not tracked by Git.
